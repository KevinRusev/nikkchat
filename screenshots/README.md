# Screenshots

Drop the production screenshots from nikkchat.com here with these exact filenames
so the main README renders them correctly:

| File | What to capture |
|---|---|
| `01-home.png` | Chat list / home screen with at least 2-3 conversations and presence dots |
| `02-chat.png` | An open chat with a couple of text messages and one image/video bubble |
| `03-call.png` | An active video call (or the incoming-call ringer UI) |
| `04-collections.png` | The collections grid with a few saved items |
| `05-profile.png` | Your profile page showing @tag, avatar, bio |
| `06-pwa-install.png` | The "Install app" prompt or the home-screen icon after install |

Suggested resolution: 1080 x 2340 (phone portrait) or 1440 x 900 (desktop).
PNG format. Compress with `pngquant` or TinyPNG before committing if they're huge.
